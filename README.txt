LIBERTY CITY MOD LOADER IV 1.0
for GTA IV: The Complete Edition (1.2.0.59) with Fusion Fix
Made by AnnaEnxo  -  GPL v3, the source code is on GitHub

HOW TO START
  1. Extract the zip anywhere (for example your Desktop).
  2. Open "Liberty City Mod Loader IV.exe".
  3. Done. The app finds GTA IV by itself. If it can't, go to
     Settings and press Change, then pick the folder with GTAIV.exe.

COMING FROM THE OLD VERSION?
  Delete the old app folder first, then extract this one.
  Your mods stay as they are: My Mods, on/off and order all carry over.
  For Nexus update checks, log in again with Settings > Log In with Nexus Mods
  (API keys are not used any more).

WHAT IT DOES
  - Get Mods: mod sites inside the app. Press a Download button and
    the mod opens in Install. Nexus "Mod Manager Download" works too.
  - Install: drop a .zip .rar .7z .oiv or a folder. The app shows where
    every file goes, then puts it in the right place.
  - Data files (gta.dat, handling.dat, vehicles.ide, carcols, cargrp...)
    get the new lines added for you. Nothing to edit by hand.
  - Texture mixing: two mods change the same texture file (like two HUD
    mods)? The app mixes them picture by picture, so you get both.
  - My Mods: tick = on/off, drag = order (the lower mod wins), updates,
    share your list, find mods you installed by hand, clean up.
  - Something wrong in the game? Play Without Mods, or Find the Broken Mod.
  - Archives: look inside .img and .rpf files, take files out, replace
    them, see and change the pictures in .wtd files.
  - 3D View: see cars (.wft), characters (.wdd, and Niko's parts) and
    objects (.wdr) in 3D with their pictures. Double-click one in Archives,
    press "3D" on a row in Install, or use Open 3D Model.
  - Your original game files are never changed.

NOT DONE FOR YOU
  - Graphics mods (ENB, ReShade, RTX Remix): install those by hand.
  - Mods with their own setup program (.exe): run them yourself.
